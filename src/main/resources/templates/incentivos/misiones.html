Cómo se sube de categoría

Hay tres categorías de donante, visibles públicamente junto al nombre de usuario: Colaborador, Sostenedor y Transformador. Para subir hay que completar una serie de misiones en orden: al completar una se desbloquea la siguiente. Cada misión completada otorga una insignia, que se muestra en tu perfil si la configurás como visible.

Esta sección es para personas donantes humanas.

Tipos de misión

Racha

Realizar una donación durante X meses consecutivos. Si pasa un mes completo sin donar, se pierde el progreso acumulado.

Completitud

Realizar donaciones de X categorías distintas.

Hábil Donador

Hacer una donación que supere X cantidad de bienes.

Donaciones Exitosas

Lograr X donaciones recibidas exitosamente por una entidad beneficiaria.
